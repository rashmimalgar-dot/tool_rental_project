# Tool Rental and Sharing Platform

A full-stack web application that allows users to list, rent, and borrow tools from other users.

## Features

- User registration and login
- Tool listing and management
- Add tool details, rental price, deposit, and availability
- Browse and rent available tools
- Rental request and return management
- User profile management
- Database integration for storing application data

## Tech Stack

### Frontend
- React.js
- HTML
- CSS

### Backend
- Python
- Flask
- REST APIs

### Database
- MySQL
